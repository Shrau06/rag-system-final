## 2. Technical Limitations of Current System

### A. The Subclaim Masking Trade-Off
Complete-answer verification was adopted because atomic claim decomposition collapsed into 90.9% false neutrals and 85-second latency. However, evaluating a complete multi-sentence answer as a single NLI hypothesis introduces a known theoretical trade-off:
- If an answer contains three sentences, where two are strongly supported by the text and one contains an ungrounded secondary detail, a cross-encoder evaluating the entire passage may still output $P(\text{Entailment}) \ge 0.60$ due to the overwhelming semantic mass of the supported assertions.
- While holistic entailment drastically reduces false neutrals, it does not guarantee token-level attribution.

### B. Computational Hardware (CPU Bottleneck)
All verification benchmarks in this project were executed on multi-core CPU. 
- While average latency for complete-answer verification is ~8.33 seconds per query (a massive improvement over 84.98s for claim-level), 8 seconds is still noticeable in live interactive chat.
- GPU acceleration (e.g., TensorRT-LLM or vLLM with FlashAttention-2) would drop ModernCE inference from ~1.0s per pass to $<50\text{ ms}$, bringing total verification time to $<200\text{ ms}$.

### C. Persistent Neutral Edge Cases (Q11, Q31, Q36)
Three queries failed to ground even at Stage 3 (Top-3):
- **Query 11, 31, 36**: Analysis showed that while the retrieved chunks discussed the relevant concepts, specific numerical values and comparative syntheses generated by Llama-3.1-70B were absent from the text. The verifier correctly refused to entail these answers, demonstrating proper conservative behavior.

## 3. Mandatory Future Work

### 1. Human Double-Blind Annotation Study
The immediate priority for future academic publication is completing the evaluation protocol prepared in `outputs/manual_annotation_50q.json`:
- Enlist two independent domain experts to annotate all 50 generated answers.
- Annotate each answer as *Fully Supported*, *Partially Supported*, or *Hallucinated*.
- Compute inter-annotator agreement (Cohen's $\kappa$).
- Measure the empirical calibration and precision/recall of ModernCE's entailment predictions against genuine human ground truth.

### 2. Hybrid Hierarchical Verification
To resolve the subclaim masking limitation without re-introducing premise dilution:
- Implement a **two-tier verifier**:
  1. *Tier 1 (Complete Answer)*: Fast, holistic ModernCE filter on concatenated Top-2 chunks.
  2. *Tier 2 (Targeted Sentence Sweep)*: Only if Tier 1 passes, run isolated sentence checks against the specific sentence-level alignments of the grounded chunk.

### 3. GPU Acceleration & Quantization
- Quantize `ModernCE-base-nli` using INT8/FP8 quantization (e.g., via ONNX Runtime or TensorRT).
- Benchmark throughput and verify that quantization introduces zero degradation to entailment accuracy.
